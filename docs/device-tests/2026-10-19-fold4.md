# Device test 2026-10-19, Galaxy Z Fold4 (SM-F936B, Android 14), FOLDED (cover screen 904x2316, device_state CLOSE)

Original settings: font_scale 1.0, night mode yes (both unchanged at the end). Builds: scripts/device-test/build.ts, one persistent key (.local-out/device-test/key.json).

## Headline
The game cannot reach gameplay on this device with ANY build, including the unmodified original APK. This is not a patch or pipeline problem.
- Original APK (original signature): SIGSEGV CGFontCopyName <- CTFontCreateWithName <- libApplication 0x26a944 / 0xb7a37c, right after "ApportableIAP: Query SKUs was successful" (the IAP font crash that fix-iap-store-font-crash stubs).
- With fix-iap-store-font-crash: the game loads the world ("best start pos") and ~3.5 s later crashes in the same CGFontCopyName, now via CTFramesetterSuggestFrameSizeWithConstraints (libApplication 0x2f5d44) -> CoreText layout -> CTFontCreateWithName -> CGFontCopyFullName(null). A second, unpatched site of the same Apportable CoreText problem: CoreText's default/fallback font path ("Helvetica" -> "Roboto-Regular", strings in libCoreText.so) returns a null font on Android 14 (/system/fonts/Roboto-Regular.ttf exists, so likely Skia/FreeType cannot load it, e.g. variable font). Needs a new patch (stub/guard in CoreText layout or bundle a real font); not in the registry.
- Re-signed-only build (no patches): crashes with the known CalledFromWrongThreadException (config change, fixed by fix-config-change-crash).
