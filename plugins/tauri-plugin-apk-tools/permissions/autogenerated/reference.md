## Default Permission

Allows all apk-tools commands

#### This default permission set includes the following:

- `allow-get-installed-package`
- `allow-read-installed-apk`
- `allow-request-uninstall`
- `allow-install-apk`
- `allow-can-request-installs`
- `allow-open-install-settings`
